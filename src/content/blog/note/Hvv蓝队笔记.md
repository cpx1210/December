## 2. 碎碎念

第一次打 HVV 难免有些紧张，我坐在 xx 学院网络中心的老师办公室，身边坐着三四个正式工……真的很害怕露出什么马脚。

工位的蚊子很多，而且长得小小个，飞的很快，叮人又痒又痛(不知道是不是上次大规模消杀让活下来的蚊子互相生出了更强的一代……)，

第一天工作比较多，因为要把前一天一整天加第一天一整天的告警看完，结果弄到将近十点才走。第二天比较熟悉 ISOP 和 WAF 了，于是聪哥让我可以去 ISOP 上对攻击者的 IP 进行封禁。其实我一开始不太明白手动封禁的意义，明显的攻击 WAF 会拦，攻击者的 IP 被 WAF 封了，可以用手机热点开关飞行模式，又能用新的 IP 继续打了。不过聪哥说这是攻防的心理战，如果攻击者攻击一个靶标，被封了四五次，攻击者可能也不想继续打了，毕竟要打的靶标这么多。这么多天下来，的确没见到死磕的攻击者，可能换个 IP 来个两三次就放弃了。

比较好笑的是，在封禁一个攻击者 IP 的时候，我把源 IP 和目的 IP 搞反了，把学校某个系统的 IP 封掉了。正好封完之后，老头子带我去吃饭，吃完回来，两三个老师围过来问我 xx 系统怎么登录不上了，是不是被打穿了，我慌了。刚好聪哥去 xx 单位应急了，我又不能露出实习生的马脚（因为客户不会愿意公司派实习生来），我只能强装镇定地排查，一言不发地坐在座位。这时一个老师跟我说，他排查到 WAF 就不通了。于是我想到会不会是 WAF 误封了。我在 ISOP 查 210 网段的 IP，真发现一个内网 IP，解封后，一切恢复了正常。

第三、第四天比较和平，告警不多，写写文档，封封 IP，能在下班前把报告写完，期间还有空隙摸摸鱼，把余弦大佬的个人博客主题拿来搭一个个人网站，就是现在的这个。
